Several files at once: hold Ctrl (or Shift) while picking files, or drag them onto the button. Travel Reports and Park Reports can be mixed: all trips are copied first, then all stops. Leave Driver name and Plate No. blank when the files are for different drivers. Travel Report: each trip is copied into the next empty row of the Activity Log sheet (Date, Driver Name, Plate No., From, From Coordinates, Depart Time, To, To Coordinates, Arrive Time); for trips already in the log only the blank cells are filled in. Park Report: each stop is merged into the trip row it belongs to (Park Count, Park Time, Park Address, Park Coordinates). Stops on a day with no trip in the log get their own parking-only row (no depart or arrive time); if you import that day's Travel Report later, import the Park Report again to move the stops onto the trips. The driver and plate come from the SinoTrack device name (“T05_RJP 162 - Gonzaga” → plate RJP 162, driver Gonzaga) unless you type them above. If the workbook is open in Excel, the cells are typed into it there and Excel saves it (so finish editing any cell first). A backup copy is saved in the backups folder each time.
